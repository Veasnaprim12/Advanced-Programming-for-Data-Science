# TP03: Class Activities

## Introduction

The objective of TP03 was to discover the Hugging Face ecosystem and learn
how pre-trained artificial intelligence models can be adapted to a specific
task through fine-tuning.

Hugging Face provides tools and resources for machine learning and natural
language processing. Its ecosystem includes the Transformers, Datasets,
Tokenizers, and Hub libraries. The Hugging Face Hub is an online platform
where users can find pre-trained models, datasets, documentation, and
examples. Users can also share their own models and results.

Instead of training a model from the beginning, we can start with a model that
has already learned general language patterns from a large collection of data.
We then adapt it to a smaller, specialized dataset. This adaptation process is
called **fine-tuning**.

## Introduction to Hugging Face

During the first activity, we learned how to use the main components of
Hugging Face.

### Hugging Face Hub

The Hugging Face Hub contains:

- Pre-trained language, vision, and audio models.
- Public datasets for machine learning projects.
- Tokenizers adapted to different models.
- Documentation and examples.
- Model cards describing training data, intended use, and limitations.

A model can be selected according to its architecture, language, task, and
size. Models can be used for text classification, sentiment analysis,
question answering, text generation, translation, and summarization.

### Transformers Library

The `transformers` library provides implementations of modern transformer
models. It allows us to load a model and its tokenizer with only a few lines
of Python code:

```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification

model_name = "distilbert-base-uncased"

tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForSequenceClassification.from_pretrained(
    model_name,
    num_labels=2
)
```

A tokenizer transforms text into numerical representations that a model can
understand. The model processes these inputs and produces predictions.

### Datasets Library

The `datasets` library is used to load, inspect, transform, split, and prepare
datasets:

```python
from datasets import load_dataset

dataset = load_dataset("imdb")
print(dataset)
```

A dataset commonly contains a training set, a validation set, and a test set.
The training set is used to update the model, the validation set is used to
monitor the training process, and the test set is used for the final
evaluation.

### Pipelines

Hugging Face pipelines provide a simple way to use a pre-trained model for
inference:

```python
from transformers import pipeline

classifier = pipeline("sentiment-analysis")
result = classifier("This course is very interesting.")
print(result)
```

This activity showed the difference between using a pre-trained model
directly and fine-tuning a model for a particular dataset and task.

## Fine-Tuning Activity

The second part of the TP focused on the complete fine-tuning process. The
objective was to adapt a pre-trained transformer model to a supervised text
classification problem.

Fine-tuning does not train a model from zero. The model starts with knowledge
learned during pre-training, and its parameters are adjusted using a
task-specific dataset.

## Step 1: Install and Import the Libraries

We first installed and imported the libraries required for the experiment:

```python
!pip install transformers datasets evaluate accelerate
```

The main libraries were:

- `transformers` for loading the tokenizer and model.
- `datasets` for loading and preparing the data.
- `evaluate` for calculating evaluation metrics.
- `accelerate` for supporting the training process.

```python
from datasets import load_dataset
from transformers import (
    AutoTokenizer,
    AutoModelForSequenceClassification,
    TrainingArguments,
    Trainer
)
import evaluate
import numpy as np
```

## Step 2: Load and Inspect the Dataset

We loaded a dataset containing text reviews and their labels:

```python
dataset = load_dataset("imdb")
print(dataset)
print(dataset["train"][0])
print(dataset["train"].features)
```

Inspecting the data helped us identify the text column, label column, number
of classes, example format, and number of observations in each split. This
step is important because the model and preprocessing function must match the
dataset structure.

## Step 3: Select a Pre-Trained Model

We selected DistilBERT as the base model:

```python
model_checkpoint = "distilbert-base-uncased"
```

DistilBERT is a smaller and faster version of BERT. It already learned useful
language representations from a large text corpus and can be adapted to a
binary classification task.

## Step 4: Load the Tokenizer

Before text can be processed by the model, it must be tokenized:

```python
tokenizer = AutoTokenizer.from_pretrained(model_checkpoint)
```

The tokenizer splits text into tokens, converts tokens into numerical IDs,
adds special tokens, creates attention masks, and pads or truncates sequences.
We defined a preprocessing function as follows:

```python
def tokenize_function(examples):
    return tokenizer(
        examples["text"],
        truncation=True,
        padding="max_length",
        max_length=256
    )
```

Truncation shortens texts that are too long, while padding gives all examples
a consistent input size.

## Step 5: Tokenize the Dataset

We applied the preprocessing function to the complete dataset:

```python
tokenized_dataset = dataset.map(
    tokenize_function,
    batched=True
)
```

Using `batched=True` processes several examples at once and is more efficient.
After this step, every example contained the tokenized inputs required by the
model as well as its original label.

## Step 6: Prepare the Model

We loaded the pre-trained model with a classification head:

```python
model = AutoModelForSequenceClassification.from_pretrained(
    model_checkpoint,
    num_labels=2
)
```

The `num_labels=2` argument indicates that the task has two possible classes.
For a task with more categories, this value must be changed. If the original
model does not have a classification head for the selected task, Hugging Face
creates one so that it can be trained during fine-tuning.

## Step 7: Define the Evaluation Metric

We used accuracy to measure the quality of the predictions:

```python
accuracy = evaluate.load("accuracy")

def compute_metrics(eval_pred):
    logits, labels = eval_pred
    predictions = np.argmax(logits, axis=-1)
    return accuracy.compute(
        predictions=predictions,
        references=labels
    )
```

The model returns logits, which are scores for each class. `np.argmax`
selects the class with the highest score. Accuracy is the proportion of
correct predictions. Precision, recall, and F1-score could also be used when
they are more appropriate for the task.

## Step 8: Configure the Training Parameters

We configured the training process with `TrainingArguments`:

```python
training_args = TrainingArguments(
    output_dir="./results",
    evaluation_strategy="epoch",
    save_strategy="epoch",
    learning_rate=2e-5,
    per_device_train_batch_size=16,
    per_device_eval_batch_size=16,
    num_train_epochs=2,
    weight_decay=0.01,
    load_best_model_at_end=True,
    report_to="none"
)
```

The important parameters were:

- `output_dir`: directory where checkpoints and results are saved.
- `evaluation_strategy`: when the model is evaluated.
- `save_strategy`: when checkpoints are saved.
- `learning_rate`: size of the parameter updates.
- `per_device_train_batch_size`: number of examples in each training batch.
- `per_device_eval_batch_size`: number of examples in each evaluation batch.
- `num_train_epochs`: number of complete passes through the training data.
- `weight_decay`: regularization used to reduce overfitting.
- `load_best_model_at_end`: restores the checkpoint with the best result.

The learning rate and number of epochs must be selected carefully. A learning
rate that is too large can damage the knowledge learned during pre-training,
while a rate that is too small can make training unnecessarily slow.

## Step 9: Create the Trainer

The `Trainer` combined the model, datasets, training configuration, tokenizer,
and evaluation function:

```python
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=tokenized_dataset["train"],
    eval_dataset=tokenized_dataset["test"],
    tokenizer=tokenizer,
    compute_metrics=compute_metrics
)
```

The trainer creates batches, sends data to the model, calculates the loss,
updates the parameters, evaluates the model, saves checkpoints, and computes
the selected metrics.

## Step 10: Fine-Tune the Model

We started the training process with:

```python
trainer.train()
```

During training, the model compared its predictions with the correct labels.
The difference was measured by a loss function. The optimizer used this loss
to update the model parameters. This process was repeated for every batch and
for every training epoch.

We monitored the training loss, evaluation loss, accuracy, completed epochs,
and saved checkpoints. A decreasing training loss usually indicates learning,
but validation performance must also be monitored to detect overfitting.

## Step 11: Evaluate the Fine-Tuned Model

After training, we evaluated the model on data that was not used to update its
parameters:

```python
evaluation_results = trainer.evaluate()
print(evaluation_results)
```

Evaluation measured how well the model generalized to new examples. The
results could include evaluation loss, accuracy, runtime, number of examples,
and processing speed.

## Step 12: Test the Model on New Text

We tested the fine-tuned model with a new sentence:

```python
text = "The movie was excellent and very enjoyable."
inputs = tokenizer(text, return_tensors="pt")

outputs = model(**inputs)
prediction = outputs.logits.argmax(dim=-1).item()

print(prediction)
```

The tokenizer converted the new text into the same format used during
training. The model generated logits, and the class with the highest logit
was selected as the prediction.

The model could also be used through a pipeline:

```python
from transformers import pipeline

classifier = pipeline(
    "text-classification",
    model=model,
    tokenizer=tokenizer
)

print(classifier("The movie was excellent and very enjoyable."))
```

Testing new examples confirmed that the workflow worked outside the training
dataset.

## Step 13: Save the Fine-Tuned Model

We saved the model and tokenizer so that they could be reused without
repeating the training process:

```python
trainer.save_model("./fine-tuned-model")
tokenizer.save_pretrained("./fine-tuned-model")
```

## Step 14: Publish the Model to the Hugging Face Hub

If authentication was configured, the model could be uploaded to the Hub:

```python
trainer.push_to_hub()
```

A published model should include documentation describing the original model,
dataset, task, training parameters, evaluation results, limitations, ethical
considerations, and example usage. This documentation helps other users
understand and reproduce the results.

## Important Concepts Learned

The TP helped us understand that:

- Hugging Face provides a complete ecosystem for modern machine learning.
- Pre-trained models can be reused instead of training from scratch.
- Tokenization converts human language into numerical model inputs.
- Fine-tuning adapts a general model to a specific supervised task.
- Training and evaluation data must be separated.
- Hyperparameters affect the speed and quality of training.
- Evaluation metrics measure model performance.
- Checkpoints preserve progress during training.
- A fine-tuned model can be saved, reused, and published.
