## Class Activities

During the class, we learned how to write clean code and how to prepare our
code properly. We discussed the importance of using meaningful names,
organizing instructions clearly, avoiding unnecessary complexity, and following
consistent coding conventions. These practices make code easier for another
person to understand and modify.

The teacher reviewed several important Python concepts with us:

- A **variable** stores a value that can be used by a program.
- A **function** is a reusable block of code that performs a specific task.
- A **class** is a structure used to define objects and their properties and
  behavior.
- A **method** is a function that belongs to a class or an object.
- A **constant** is a value that should normally remain unchanged during the
  execution of a program.
- A **package** is a collection of related Python modules organized in a
  directory. Packages help us organize and reuse code in larger projects.
- **PEP 8** is the Python style guide. It gives recommendations for writing
  consistent, readable, and well-organized Python code.

We also reviewed how these concepts work together in a Python program. Good
variable names describe the data, functions divide a program into manageable
tasks, classes organize related data and behavior, methods define actions that
objects can perform, and packages organize related modules.

### Answer to the Teacher's Question: What Is a Constant?

A constant is a value that is given a name and is intended not to change while
the program is running. In Python, constants are usually written with
uppercase letters to show this intention. For example:

```python
PI = 3.14159
MAX_STUDENTS = 30
```

Python does not strictly prevent a constant from being changed, but using
uppercase names tells other programmers that the value should remain the same.

In conclusion, the main activity of the class was to review the foundations of

such as variables, functions, classes, methods, packages, and constants helps
us write more understandable and maintainable code. This knowledge will be
useful for our future programming and data-science work.
